# Climate Action Lab

A local, browser-based climate scenario simulator for a class project. The team is collaborating in one GitHub repository using assigned folders:

- `Engine/` — scenario calculations and recommendation rules (Shashank Chandra)
- `UI/` — interface and chart
- `Data/` — benchmark data and source notes

The files in these folders are currently placeholders. The team has not chosen the exact interface between them yet.

## Agreed direction

- Build a dashboard with a simulator for several area-level changes, including reduced oil consumption.
- Let the user inspect both 2030 and 2035 outcomes.
- Use percentage sliders for scenario changes.
- Have the Engine read scenario inputs from `Data/`.
- Combine an annual reduction rate and policy boost by adding their percentage points.
- Label modeled benefits and disclose the assumptions and source data behind them.
